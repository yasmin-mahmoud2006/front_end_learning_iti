2. Display Types 
Every element in HTML behaves in a specific way regarding its layout and space:
 * Block Elements: Elements that take up the full width available and always start on a new line (e.g., div, p, h1-h6).
 * Inline Elements: Elements that take only as much width as necessary and flow side-by-side without starting a new line (e.g., span, a, strong).
